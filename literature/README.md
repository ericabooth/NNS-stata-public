# Literature Folder

This folder keeps background sources out of the project root.

- `core_nns/`: NNS, partial-moment, clustering, and segmentation references used to motivate `nnsreg`.
- `comparators/`: kernel/nonparametric comparator references, including `np` package background.
- `working_papers/`: reserved for additional drafts or notes that are relevant but not yet cited.

The rough implementation-planning PDF is stored in `manuscript/background/` because it is project-specific background rather than citable literature.
