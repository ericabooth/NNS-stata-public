# Implementation Plan: nnsreg (Nonlinear Nonparametric Statistics in Stata)

This document outlines the design and implementation strategy for the new Stata package `nnsreg`, which implements Nonlinear Nonparametric Statistics (NNS) regression based on partial moments and hierarchical clustering. It also outlines the accompanying Stata Journal manuscript, test suite, and web resources.

## Goal Description

Implement a fully documented, high-performing NNS regression package for Stata using only Stata code and Mata. The command will support:
1. **Adaptive clustering**: Data-driven partitioning of the independent variable using partial moments.
2. **Flexible estimation**: Piecewise linear fitting by either connecting quadrant means (`method(connect)`) or fitting a linear spline via OLS (`method(ols)`).
3. **Integration with Stata post-estimation**: Complete compatibility with `estimates store`, `estimates table`, `predict`, `margins`, and plotting commands like `coefplot`.
4. **Reproducible policy applications**: Illustrating NNS on two simulated Texas-focused policy datasets (school spending vs. test scores, and infrastructure age vs. water loss).
5. **Stata Journal manuscript**: Written in LaTeX using the official `statapress` style.
6. **Ancillary resources**: GitHub distribution files, an HTML documentation page using `webdoc2`, and interactive visualizations using `statashiny`.

## User Review Required

> [!IMPORTANT]
> **Use Case Selection**: We have replaced the generic use cases in the rough plan with two highly specific, Texas-relevant policy use cases aligned with Eric's role at Texas 2036:
> 1. **School District Spending and Student Achievement**: Non-linear relationship with diminishing marginal returns.
> 2. **Water Infrastructure Age and Water Loss**: Non-linear relationship showing threshold breakdown effects.
>
> Please confirm if these use cases are suitable for the manuscript.

> [!NOTE]
> **Spline Formulation**: By reformulating both standard NNS (connecting quadrant means) and OLS NNS as a linear spline regression on data-driven knots, we achieve native compatibility with all of Stata's post-estimation features (like `predict`, `margins`, `estimates store`, and `coefplot`).

## Proposed Changes

### Component 1: Stata Package Code (`code/`)

#### [NEW] [nnsreg.ado](file:///Users/ericbooth/Library/CloudStorage/GoogleDrive-eric.booth@texas2036.org/My%20Drive/NNS-stata-public/code/nnsreg.ado)
Stata wrapper and estimation command. It will:
- Parse syntax: `nnsreg depvar indepvar [if] [in] [, order(integer) noise(string) method(string) noplot graph_opts(string) generate(string)]`
- Call Mata for binary-heap hierarchical partitioning and knot selection.
- Generate spline basis variables at the partitioned knots.
- Fit the model using OLS and optionally overwrite the coefficient vector with the exact NNS quadrant-mean connections.
- Post estimation results using `ereturn post` to enable post-estimation tools.

#### [NEW] [nnsreg_p.ado](file:///Users/ericbooth/Library/CloudStorage/GoogleDrive-eric.booth@texas2036.org/My%20Drive/NNS-stata-public/code/nnsreg_p.ado)
Post-estimation prediction command. It will:
- Recreate the spline basis dynamically on prediction evaluation points (supporting out-of-sample extrapolation).
- Compute fitted values using `e(b)` and store them in the target variable.

#### [NEW] [nnsreg.sthlp](file:///Users/ericbooth/Library/CloudStorage/GoogleDrive-eric.booth@texas2036.org/My%20Drive/NNS-stata-public/code/nnsreg.sthlp)
